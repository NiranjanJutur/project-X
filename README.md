# Project X

Project X is a mobile-first personal finance app starter focused on one core habit: logging income and expenses in seconds.

## What is included

- Fast-add main screen with expense and income toggle
- Tap-first numeric keypad so users can log without relying on the keyboard
- Dynamic category pills that switch with the selected transaction type
- Live summary cards for today and for the active date range
- Recent transactions feed with local persistence in `localStorage`
- Save toast with undo support

## Stack

- React 19
- TypeScript
- Vite
- Plain CSS with a custom visual system

## Getting started

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```
